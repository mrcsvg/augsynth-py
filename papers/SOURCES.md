# Papers — fontes

Referências canônicas do projeto (ver [`../CLAUDE.md`](../CLAUDE.md), seção
*Canonical references*), com as URLs open-access e os DOIs publicados.

**Os PDFs não são versionados neste repositório** — são material de terceiros
(preprints/working papers open-access) e redistribuí-los num repo público é
zona cinzenta de copyright. Baixe as cópias de leitura localmente a partir
das URLs abaixo; `papers/*.pdf` está no `.gitignore`, então cópias locais
nesta pasta nunca entram em commits.

As versões finais publicadas (JASA / JEL / Political Analysis) estão atrás de
paywall e podem diferir em paginação. Use as versões open-access como
referência de conteúdo; para citação com paginação exata da revista, consulte
o DOI publicado.
